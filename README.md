# To-Do List App (Java)

A simple to-do list app. The backend is written in Java and the web page uses HTML, CSS and JavaScript.

## Features
- Add tasks
- Mark tasks as done
- Delete tasks
- Filter by All, To do and Done
- Clear all completed tasks

## How to run
1. Run `TodoApp.java`
2. Open http://localhost:8081 in your browser

## Project structure
- `src/TodoApp.java` - the Java server that saves and serves the tasks
- `public/` - the web page (HTML, CSS and JavaScript)
- `Dockerfile` - used to deploy the app online
